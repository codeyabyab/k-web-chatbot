# K Web Chatbot

A side-project that features a chatbot inside a web application that uses OpenRouter's free DeepSeek R1 API.

## Features
- Generates automated and reliable responses to user prompts.
- Supports conversational interaction through a straightforward UI.

## Tech Stack used in Development

**Frontend**
- React
- Tailwind CSS
- FontAwesome

**Backend**
- OpenRouter API (DeepSeek R1 model)

**Build Tools**
- Node.js / npm
- Vite

**Deployment**
- Vercel

## Reflection
I wanted to try and create a chatbot of my own since it is the trending technology nowadays, thanks to AI. Regardless, it was a pleasant surprise on how simple it is to develop thanks to existing APIs.
